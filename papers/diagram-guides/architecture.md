# Architecture

LocalXiv adaptation of diagram-design semantic layout guidance (MIT).

Show inputs, component operations, parallel or repeated blocks and outputs. Preserve all required
inputs at each block. Use consistent symbols from the concrete example through the system context.
Use raw SVG geometry to distinguish branching, masking, feedback and cross-block wiring.

Use the built-in LocalXiv palette and sans-serif font. Route arrows through open space, clear of
labels. Use numeric geometry, supported transforms and local marker references. Do not use scripts,
external assets, embedded images or upstream skin examples. Shorten labels and simplify secondary
detail before reducing spacing.
