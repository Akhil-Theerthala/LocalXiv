# Included example

Attention Is All You Need, arXiv:1706.03762v7, by Ashish Vaswani and coauthors.
Source: https://arxiv.org/abs/1706.03762v7

This offline example includes the locally parsed paper, original PDF, EPUBs,
visual overview, blog, and editable HTML/SVG figures with PNG and PDF exports.
The explanations were copied from the reviewed local ToolCallingAgent run of
2026-09-10, revision `smolagents-tool-html-v2`. Both passed their final saved
review and match the included paper digest. They were not regenerated with the
current prompt revision. Their model and source provenance remain in sample.json.
They are generated explanations, not author text.
No credentials, account settings, chat history, or generation requests are included.

Application startup installs this example once into each library. Existing copies
are preserved. Removing it from the library keeps it removed on later launches.
The release builder includes this directory with the app source.
