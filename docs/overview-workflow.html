Each request runs either Overview or Blog. Both use the same reading, rendering and review stages. A Blog can reuse an existing overview; it never requires one.

One ToolCallingAgent per request, plus a separate model review call. HTML/SVG is the authored visual source; WebKit produces static exports. Bounded retries stop on failure and keep the previous saved output. Blog-only requests generate directly when no reusable overview exists. CodeAgent and Manim are deferred.
