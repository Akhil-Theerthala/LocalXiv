# LocalXiv 0.0.12

Read arXiv papers comfortably on your Mac, then take them to Kindle. This preview improves visual Overview planning and recovery, lets free-sized Overviews fill the reading column, and updates the README for the Product Hunt GPT-6 Astra Challenge.

## Changes

- Overview drawing and repair requests retain shared teaching context and layout intent. Planning preserves the paper's narrative and scientific expressions instead of cutting them into misleading fragments.
- Planner corrections stay within the existing request budget. Recovery records lost panels and relationships and retains unresolved scientific review findings.
- Free-sized Overviews fill the reader's available column width.
- Developers can explicitly invoke a live generation smoke check. Ordinary test runs use offline CLI tests and do not make paid provider calls.
- The README explains the reading workflow, includes a saved example figure, and distinguishes development with Astra in Codex from the provider selected inside the app.

## Verification and limitations

The release workflow checks the source, builds the portable app, runs native renderer tests, and verifies the packaged runtime after moving the app. Attached assets include the verification report, runtime inventory, exact app source, dependency source inputs, and SHA-256 checksums.

Local verification ran 447 tests with native rendering enabled: 446 passed and the opt-in Keychain smoke check was skipped. JavaScript UI checks, source compilation, shell syntax, workflow YAML, version metadata, documentation links, and the dependency source-collector self-check also passed.

Offline tests use scripted provider responses. They verify recovery and export behavior, not live-provider reliability, scientific accuracy, generation speed, or cost. No new paid generation is part of this release's verification. The included example was generated with an earlier workflow; see its provenance in the repository.

AI explanations remain experimental. Generation may take several minutes or fail, and generated claims need checking against the paper. The previously documented Blog review limitations remain: findings on the same passage can share an ID, and a finding targeting an omitted figure can bypass anchor validation. This release does not claim to resolve those cases.

AI requests send selected paper content and, where applicable, images to your configured provider and may incur charges. Importing, reading, and exporting papers do not require AI credentials.

## Installation

Requires Apple Silicon and macOS 26 or newer. Download the DMG and drag LocalXiv into Applications. Finish active jobs before updating. Your library and settings remain on your Mac. Updater-enabled builds can use **LocalXiv → Check for Updates…** once the signed feed is published.

This preview is ad hoc signed, without Apple Developer ID signing or notarization. macOS may block the first launch. The Sparkle update feed is signed separately with the project's local update key. Separate-Mac installation and actual Kindle delivery are not covered by the automated checks.
