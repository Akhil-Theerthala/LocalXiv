# LocalXiv 0.1.1

This release adds Chat to the Blog view, accepts Hugging Face and Papers with Code links, and finds the arXiv Paper of a bibliography entry. An optional Papers with Code setting adds search results, GitHub stars, and official code repositories.

## Changes

- **Chat in the Blog.** Ask, Explain, and Ask About the Paper also work in the Blog view. The Question card opens in a panel beside the Blog. The selected Blog words go with the question as a quote, on the passage of the nearest Blog citation. The Paper view shows the card at that passage, and All Notes lists it.
- **More links for Direct import.** Paste a Hugging Face paper link or a Papers with Code paper link to add its arXiv Paper. A `paperswithcode.co/paper/<number>` link sends that number to paperswithcode.co to find the arXiv ID.
- **Find Paper.** The Reference preview of a bibliography entry with an arXiv ID has Open or Add. For an entry with no arXiv ID, Find Paper looks for the arXiv Paper with the same title.
- **Code link.** The Paper shows its own code repository or project page from its text. A link to a cited implementation or to a Hugging Face paper page is not a Code link. A GitHub or GitLab link must name an owner and a repository.
- **Papers with Code setting.** With **Settings → Search → Use Papers with Code**, Paper search has a Papers with Code lane, Find Paper tries Papers with Code first, and the Code link shows GitHub stars and the official repository when the text has none. The setting is off by default.
- **Contacted hosts.** The README lists each host that LocalXiv contacts and the data it sends to each.
- **Reading state fix.** With SQLite 3.53 or newer, the library sent the Reading state of a Paper as text, so Recent, Resume reading, and the New, Reading, and Read marks did not work. The library sends it as a record again.

## Verification and limitations

The release workflow checks the source, builds the portable app, runs native renderer tests, and verifies the packaged runtime after moving the app.

For this release, ruff found no problems. On Python 3.14 with SQLite 3.54.1, the component suite ran 230 tests: 9 skipped and 1 failure. The failure is `test_one_text`, which reads the newest local parser corpus run, and that run has no `document.json` files.

Chat in the Blog was checked in the browser shell with a scripted provider: the selection bar, Ask, Explain, Ask About the Paper, the saved card, the card in the Paper view, and the Split view. The Blog context menu in the Mac app was not run.

Open items:

- The Blog panel has no Add Quote. Undo after Discard in the Blog brings the card back only in the Paper view. Clear Chat works only in the Paper view.
- The open items of 0.1.0 stay.

AI explanations and Chat remain experimental. AI requests send selected paper content, and for Chat the Highlights and Notes of the Paper, to your configured provider and may incur charges. With the Papers with Code setting on, LocalXiv sends search text, bibliography titles, and the arXiv IDs of the Papers you open to paperswithcode.co.

## Installation

Requires Apple Silicon and macOS 26 or newer. Download the DMG and drag LocalXiv into Applications. Finish active jobs before updating. Your library and settings remain on your Mac. Updater-enabled builds can use **LocalXiv → Check for Updates…**.

This preview is ad hoc signed, without Apple Developer ID signing or notarization. macOS may block the first launch.
